# BodySlide and Outfit Studio Guides

[Back to repository home](../../README.md)

Practical Fallout 4 procedures for converting and validating outfit projects with BodySlide and Outfit Studio.

## Published Guide

- [Converting CBBE outfits to Fusion Girl](cbbe-to-fusion-girl.md)

## Scope

The guide documents an independently written workflow based on practical testing and credited community references.

No body meshes, conversion templates, outfit assets, screenshots, PDFs, or third-party documentation are redistributed.

Every outfit has its own topology, weights, sliders, slots, and permissions. Back up source projects, validate the generated meshes in game, and obtain the original author's permission before publishing a converted outfit when required.
