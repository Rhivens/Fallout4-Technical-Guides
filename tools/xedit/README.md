# xEdit Tools

[Back to repository home](../../README.md)

Small, focused xEdit scripts developed and validated during real Fallout 4 load-order audits.

## Published Tools

- [Pervert Location Loss Scanner](pervert-location-loss-scanner/README.md) — read-only scanner for lost `XLRL` and `XLCN` values defined by `pervert.esp`.

## Scope

These tools do not replace manual conflict analysis. Read each tool's requirements, tested scope, known limitations, and validation notes before using it.

Always back up the load order and inspect every reported conflict before creating a compatibility patch.
