## Documentation Labels

Each guide identifies its scope:

- **Tested guide:** records a procedure that was actually performed and validated on the stated setup.
- **Generic checklist:** provides a safe decision framework but is not a universal preset.
- **Historical reference:** preserves an older working method that may require adaptation.

Version-specific values must never be assumed to apply to a newer release without checking the current mod description, requirements, file notes and changelog.
